## 핵심

```
1강

├─ 출력: print (프린트), f-string (에프 스트링)
```

## 변수는 이름표

C#의 `int hp = 100;`은 "int 크기의 상자에 100을 넣는다"이고,
파이썬의 `hp = 100`은 "100이라는 값에 hp라는 이름표를 붙인다"입니다.

```
C#        [ hp: 100 ]        상자 안에 값이 들어 있음
파이썬     hp ──▶ (100)       이름표가 값을 가리킴
```

- 같은 이름표를 다른 종류의 값에 옮겨 붙일 수 있음: `x = 100` 다음에 `x = "hello"` 가능
- 이름표 두 개가 같은 값을 가리킬 수 있음

```python
a = [1, 2]
b = a          # 복사가 아니라 이름표를 하나 더 붙인 것
b.append(3)
print(a)       # [1, 2, 3]
```

## 기본 자료형

| 파이썬 | 읽기 | 예시 | C# 대응 | 다른 점 |
|---|---|---|---|---|
| `int` | 인트 | `62` | `int`, `long` | 크기 제한 없음 |
| `float` | 플로트 | `45.5` | `double` | `f` 접미사 없음 |
| `str` | 스트링 | `"ARM-01"` | `string` | `'...'`도 같음, `char` 없음 |
| `bool` | 불 | `True` | `bool` | 첫 글자 대문자 |
| `None` | 논 | `None` | `null` | "값 없음" |

- 타입 확인: `type(값)`
- 타입 변환: `int("62")`, `float("45.5")`, `str(62)` (C#의 `int.Parse`와 같은 역할)

## 출력

- `Debug.Log` / `Console.WriteLine` 대신 `print()`
- `$"HP: {hp}"` 대신 `f"HP: {hp}"`
- 주석은 `//` 대신 `#`
- `Main` 함수 없이 파일 첫 줄부터 실행

## 나눗셈 기호 (함정)

```
├─ /   항상 실수 나눗셈    7 / 2  → 3.5
├─ //  몫 (소수점 버림)    7 // 2 → 3     ← C#의 정수 나눗셈
└─ %   나머지             7 % 2  → 1
```

## 확인 문제와 결과

```python
a = 7 / 2
b = 7 // 2
c = "3" + "4"
d = int("3") + 4
print(a, b, c, d)
```

정답: `3.5 3 34 7` / 결과: 4문제 중 1개 정답

| 문제 | 적은 답 | 정답 | 틀린 이유 |
|---|---|---|---|
| a | 3 | 3.5 | C# 습관. 파이썬 `/`는 항상 실수 |
| b | 0.5 | 3 | `//`는 몫. 나머지는 `%` |
| c | 34 | "34" | 정답 (문자열 이어 붙이기) |
| d | 에러 | 7 | `int("3")`은 숫자 3으로 변환. 에러는 `"3" + 4`일 때 |
