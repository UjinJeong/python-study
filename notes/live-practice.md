# 실습. 하드웨어 데이터 실시간 시각화

코드: [`fake_robot.py`](../fake_robot.py), [`live_graph.py`](../live_graph.py)

## 목표

실제 로봇 없이 "로봇인 척하는 프로그램"을 만들어, 받는 쪽은 진짜 하드웨어와 같은 방식으로 데이터를 받게 한다.
나중에 보내는 쪽만 진짜 장비로 바꾸면 그대로 동작한다.

```
fake_robot.py (페이크 로봇)
   │  UDP (유디피) 통신, 0.1초마다 각도와 온도
   ▼
live_graph.py (라이브 그래프)  →  실시간 그래프
```

## 단계별 계획

```
├─ 1단계 가짜 로봇 + 실시간 그래프   ← 코드 완성, 실행 확인 필요
├─ 2단계 진짜 센서로 바꾸기 (택1)
│    ├─ 스마트폰 센서 ── phyphox (피폭스) 앱, 무료
│    └─ Arduino (아두이노) ── USB로 센서값 전송
└─ 3단계 Unity (유니티)로 3D 표현 (= 7강)
```

## 실행 방법

```
터미널 1 (받는 쪽 먼저):   python live_graph.py
터미널 2 (보내는 쪽):      python fake_robot.py
끄기: 그래프 창 닫기, 터미널 2에서 Ctrl + C
```

VS Code 터미널 영역 오른쪽 위 `+` 버튼으로 터미널을 하나 더 연다.
Windows 방화벽 창이 뜨면 허용 (내 PC 안의 통신).

## 정상 화면

- 위 (각도): 0도 ~ 90도를 물결 모양으로 왕복
- 아래 (온도): 조금씩 오르다가 70도를 넘으면 55도로 떨어짐
- 제목: 현재 온도와 정상 / 과열! 이 실시간으로 바뀜
- 10초가 지나면 최근 10초만 보이며 왼쪽으로 밀림

## 새로 나온 개념

```
보내는 쪽
├─ socket (소켓) ── 네트워크로 데이터를 주고받는 통로
├─ UDP (유디피) ── 빠르게 던지듯 보내는 방식, 센서 데이터에 많이 씀
├─ 127.0.0.1 ── 내 PC 자신
├─ PORT (포트) 5005 ── 같은 PC 안의 방 번호, 양쪽이 같아야 함
├─ JSON (제이슨) ── dict를 글자로 바꿔 보내는 형식
├─ math.sin (매스 사인) ── 물결 모양 값
├─ random (랜덤) ── 값을 살짝 흔들기
└─ while True (와일 트루) + time.sleep (타임 슬립) ── 0.1초마다 반복

받는 쪽
├─ bind (바인드) ── 5005번으로 오는 데이터를 받겠다고 등록
├─ setblocking(False) (셋 블로킹 폴스) ── 데이터 없으면 기다리지 않음
├─ deque (덱) ── 길이 제한 있는 list, 꽉 차면 오래된 값 자동 삭제
└─ FuncAnimation (펑크 애니메이션) ── 0.1초마다 update 호출  ≈ Unity Update()
```

Unity 대응: `FuncAnimation` ≈ `MonoBehaviour.Update()`, UDP ≈ `UdpClient`
